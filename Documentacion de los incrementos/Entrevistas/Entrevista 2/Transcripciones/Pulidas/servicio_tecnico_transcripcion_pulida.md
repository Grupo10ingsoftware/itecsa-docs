# Entrevista de levantamiento de proceso: Servicio técnico

## Naturaleza del documento
Este documento corresponde a una entrevista realizada a un técnico del área de servicio técnico. Su objetivo es levantar, ordenar y clarificar el proceso general de atención técnica, diferenciando entre clientes con contrato, clientes sin contrato, modalidades de atención y subprocesos asociados.

La versión fue pulida a partir de una transcripción oral con errores de reconocimiento. Se normalizaron términos técnicos, se eliminaron repeticiones y se anonimizaron los nombres propios.

## Convenciones usadas en esta versión
- **Manager**: sistema principal usado para ciertas gestiones operativas y documentales.
- **Servicetonic**: sistema principal del área para gestión del ciclo técnico.
- **Google Sheets (en Google Drive)**: soporte que puede existir en otras áreas, pero que no aparece como sistema principal aquí.

## Alcance de la entrevista
La entrevista se centró en:
- cómo ingresa una solicitud de soporte;
- cómo se clasifica el tipo de atención;
- cómo se gestiona el diagnóstico;
- cómo se coordina la reparación;
- cómo se registran los datos;
- y qué ocurre en el caso de equipos nuevos antes de su entrega.

No se profundizó en valores comerciales específicos, porque esos son manejados por ventas.

## Descripción general del área
Según lo indicado por el técnico, el área atiende principalmente equipos relacionados con:
- impresoras de credenciales;
- impresoras para tarjetas con activos, como débito, crédito, alimentación, tarjetas internas u otras similares;
- impresoras de etiquetado, tanto de sobremesa como industriales.

Se aclara que algunas máquinas operan con lógicas similares, pero que las impresoras usadas sobre tarjetas con activos requieren mayores resguardos por el valor y sensibilidad del producto.

## Ingreso de solicitudes de servicio técnico
### Cliente con contrato
Cuando el cliente tiene contrato, el requerimiento entra por **mesa de ayuda**. Se levanta un ticket y se contacta al cliente para identificar:
- cuál es el problema;
- desde cuándo ocurre;
- qué síntomas presenta la máquina;
- y si el problema podría resolverse de forma remota o requiere atención adicional.

### Cliente sin contrato
Cuando el cliente no tiene contrato, el proceso comienza por **ventas**. Ventas realiza una primera revisión o checklist. Si no logra resolver el problema, el caso se deriva a mesa de ayuda / servicio técnico para continuar el diagnóstico.

## Diagnóstico inicial y modalidades de atención
Una vez levantado el ticket, existen tres modalidades principales:
1. **soporte remoto**;
2. **visita técnica a terreno**;
3. **ingreso de la máquina al taller**.

La decisión depende del tipo de falla detectada y de lo que el cliente acepte. Los valores son gestionados por ventas.

### Soporte remoto
Si el problema puede resolverse sin intervención física, el caso se atiende de forma remota desde servicio técnico.

### Visita a terreno
Si el problema no puede resolverse por teléfono o soporte remoto, se puede enviar un técnico a terreno. Durante la visita:
- el técnico evalúa el equipo;
- registra lo observado;
- y, si detecta la necesidad de repuestos o reparación mayor, reporta esa información para que ventas pueda cotizar.

En estos casos se genera una **orden de trabajo**.

### Ingreso a taller
Si el problema no puede resolverse en terreno o requiere revisión más profunda, la máquina ingresa al taller. Según la entrevista:
- el plazo total aproximado puede ser de **alrededor de una semana**;
- existe un plazo de **48 horas** para entregar un informe inicial al cliente.

## Resolución del servicio y relación con ventas
El flujo que se desprende de la entrevista es:
1. se recibe el caso;
2. se realiza diagnóstico inicial;
3. se determina si corresponde soporte remoto, terreno o taller;
4. si hay costos asociados, ventas los comunica y cotiza al cliente;
5. una vez aceptada la solución, se ejecuta la atención.

Esto deja una separación clara:
- **servicio técnico** diagnostica y ejecuta la solución técnica;
- **ventas** maneja valores, condiciones y autorizaciones con el cliente.

## Casos de reincidencia o falla no resuelta
Si en terreno no se logra determinar con certeza la falla o si el problema requiere una revisión más exhaustiva, la máquina se traslada al taller. Ese ingreso puede continuar bajo el mismo servicio ya iniciado, sin necesidad de abrir un proceso totalmente nuevo.

## Equipos de reemplazo temporal
El reemplazo temporal no aplica de forma general. Según la entrevista, solo se entrega en ciertos casos a clientes con contrato y además con condiciones previamente acordadas de respaldo o backup.

## Problemas de software
Cuando el problema corresponde al software relacionado con la impresora, ese soporte también se gestiona dentro del mismo servicio técnico. En esta entrevista no se identificó una derivación formal a otro departamento para este tipo de falla.

## Sistemas utilizados por el área
### Manager
Manager se utiliza para gestiones operativas complementarias, por ejemplo:
- solicitar insumos;
- gestionar movimientos asociados al servicio;
- trabajar con documentos como la **guía de despacho**.

### Servicetonic
El sistema principal del área es **Servicetonic**. Ahí se registran datos como:
- razón social;
- ubicaciones;
- máquinas;
- números de serie;
- contactos del cliente, cuando corresponde.

Además, cuando ventas levanta un ticket técnico, este se registra en Servicetonic y desde ahí se procesa el seguimiento del caso.

## Subproceso de preparación de equipos nuevos
Además del servicio correctivo, la entrevista menciona un subproceso distinto vinculado a equipos nuevos. Cuando se trata de una venta nueva, el área técnica prepara la máquina antes de su entrega. Esto incluye:
- revisión general del equipo;
- verificación de cables y transformadores;
- incorporación de garantía;
- colocación de sellos de garantía;
- aplicación de un sticker o sello metálico con el logo de la empresa.

Este proceso no corresponde a una reparación, pero sí forma parte del trabajo técnico del área.

## Observaciones relevantes para el proyecto
- El flujo de servicio técnico es distinto al de producción.
- Existe coordinación importante entre ventas, mesa de ayuda y servicio técnico.
- **Servicetonic** aparece como sistema clave del ciclo técnico.
- Las decisiones comerciales no se toman en servicio técnico.
- El servicio contempla más de una modalidad de atención.
- El área también participa en la preparación de equipos nuevos.

## Puntos pendientes de validación
- Cómo se integra Servicetonic con otros sistemas de la empresa, si es que existe integración formal.
- Qué diferencias operativas existen entre tipos de cliente más allá del contrato.
- Qué variantes adicionales aparecen según marca o tipo de equipo.

## Síntesis breve
### Cliente con contrato
1. Cliente levanta ticket en mesa de ayuda.
2. Se realiza diagnóstico inicial.
3. Se intenta resolver por vía telefónica o remota.
4. Si no resulta, se define atención en terreno o ingreso a taller.
5. Se informa a ventas cuando corresponde cotizar.
6. Se ejecuta la solución técnica.
7. Se entrega informe u orden de trabajo según el caso.

### Cliente sin contrato
1. Cliente contacta primero a ventas.
2. Ventas realiza revisión inicial.
3. Si no se resuelve, el caso se deriva a mesa de ayuda / servicio técnico.
4. Se determina modalidad de atención.
5. Ventas comunica costos y condiciones.
6. Se ejecuta el servicio.
